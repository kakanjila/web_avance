✨ Typographie Responsive

Utilise clamp() pour scalabilité fluide:

font-size: clamp(min, optimal, max)

Min = Taille minimale
Optimal = % viewport
Max = Taille maximale

Résultat: Texte toujours lisible, proportions respectées

🖼️ Images Fluides

Adaptation automatique:

max-width: 100%
aspect-ratio: 16/10
object-fit: cover

Résultat: Aucune déformation, chargement optimisé

Padding/Margin proportionnels:
